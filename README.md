# Harsh Jat — Portfolio

A clean, responsive personal portfolio built with **HTML and CSS only**. No frameworks, no build step, no JavaScript — just static files.

## Overview

Single-page portfolio featuring:

- **Hero** — introduction with profile card and tech tags
- **About** — professional summary with focus areas (Design Accuracy, Responsive Engineering, Accessibility, Performance)
- **Skills** — tech expertise cards (HTML, CSS, Responsive Development, UI Implementation, Version Control)
- **Projects** — featured open-source work (INDIA AI Orb UI)
- **Focus** — DSA & Problem Solving, Interactive Web, Open Source
- **Contact** — email + project inquiry form

## Tech Stack

| Layer     | Technology                              |
| --------- | --------------------------------------- |
| Markup    | HTML                                    |
| Styling   | CSS (custom properties, Grid, Flexbox)  |
| Hosting   | GitHub Pages                            |

## Local Development

No build tools required. Open `index.html` directly in a browser, or serve locally:

```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx serve .
```

Then visit `http://localhost:8000`.

## Deployment

Deployed via **GitHub Pages** from the `main` branch.

**Live URL:** https://harshjat-ops.github.io/Portfolio/
